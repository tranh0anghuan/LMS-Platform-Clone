# LMS Platform 
Our Online Course Learning Platform is a cutting-edge Learning Management System (LMS) clone designed to revolutionize the way you learn, teach, and share knowledge. Whether you're an educator looking to deliver engaging courses, a student eager to upskill, or an organization seeking to train employees, this platform is your ultimate solution. 

## Tech Stack  
- **Frontend:** Next.js, Tailwind CSS, React.js, Shadcn/ui   
- **Backend:** Prisma
- **Database:** MongoDB  
- **Authentication:** Clerk
- **Payment:** Stripe
- **Other:** Mux

## Features:

- Comprehensive Course Management: Create, organize, and manage courses with ease using an intuitive interface.
- Interactive Learning Tools: Engage learners with video lectures.
- Personalized Learning Paths: Tailor courses to individual learners’ needs with customizable learning paths.
- Progress Tracking: Monitor performance with progress dashboards and detailed analytics.
- Responsive Design: Learn anytime, anywhere with a mobile-friendly platform.

## For Educators:

- Effortlessly design and publish courses.
- Monetize your content with built-in payment gateways.

## For Learners:

- Access a diverse catalog of courses across various fields.
- Learn at your own pace with flexible schedules.
